MILITARY PHYSIQUE — FREE IPHONE STARTER

Included: mobile-first workout dashboard, five Phase 4 sessions, exercise checkmarks, elapsed timer, workout history, body measurement log, personal records, photo checkpoints, and JSON backup/restore.

Important limits:
- This is a web app starter, not a native App Store app.
- Data is stored locally in the browser on this device; there is no login or cloud sync.
- Photos can use significant local storage. Export data regularly and keep original photos in iPhone Photos.
- Confirm the included workout details against your original Phase 4 plan before treating it as the final training program.

To install as a Home Screen web app, publish index.html to an HTTPS static host (for example GitHub Pages), then open the published URL in Safari and use Share > Add to Home Screen.
